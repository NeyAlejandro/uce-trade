# Frontend Layer

This directory houses the front-end applications for **UCE Trade**, built in compliance with **TC-02**, **FR-31**, **FR-36**, and **NFR-14–NFR-16**:

- **`landing/`**: Astro Jamstack informative landing page (`FR-31`, `NFR-06`).
- **`web-app/`**: Responsive React PWA using TanStack Query, packaged for Web first, Desktop via Tauri second, and Mobile via Capacitor third (`FR-36`).
