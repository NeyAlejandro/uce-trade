# Domain Microservices (`backend/services`)

Spring Boot microservices following Hexagonal Architecture (`NFR-09`):
- Identity & Access (`MS1`)
- Product Command / Ventures Management (`MS2`)
- Catalog Query & Search (`MS3`, `MS4`)
- Interactions, Chat & Reviews (`MS5`)
- Payments & Billing (`MS6`, `MS7`)
- Real-Time Notifications (`MS8`)
- Analytics & Dashboards (`MS9`)
- Audit & Traceability (`MS10`)
